# 📊 Power BI Sales Dashboard – Data Analyst Internship Task 3

## 🔍 Overview

This project is part of a Data Analyst Internship assignment. The goal was to design a fully interactive sales dashboard using **Power BI** based on a retail dataset (Superstore Sales from Kaggle). The dashboard enables business stakeholders to explore and analyze sales, profit, category trends, and regional performance.

---

## 📁 Dataset

- **Name:** Superstore Sales Dataset  
- **Source:** [Kaggle - Superstore Data](https://www.kaggle.com/datasets)  
- **Fields Included:** Order Date, Region, Segment, Category, Sub-Category, Sales, Quantity, Discount, Profit

---

## 📈 KPIs Tracked

- 🧾 **Total Sales**
- 💰 **Total Profit**
- 🧮 **Profit Margin (%)**
- 📦 **Total Quantity Sold**
- 📋 **Total Order Count**
- 🧾 **Average Order Value**
- 🎯 **Average Discount**

---

## 📊 Dashboard Features

- **Dynamic KPIs** using DAX Measures
- **Time-Series Line Charts** for sales and profit trends
- **Bar Charts** for:
  - Sales by Region
  - Sales by Category
- **Slicers** for:
  - Category
  - Segment
  - Region
  - Date (Order Date)
- **Interactive Filters** affecting all visuals
- **Clean Layout & Theme** for business presentation

---

## 🧠 Key Insights

- 📈 Sales grew consistently from 2014 to 2017
- 🖥️ Technology category had the highest revenue
- 🌍 West region dominated sales and profit
- 👤 Consumer segment led in number of orders
- ⚠️ Moderate profit margin (~12%) indicates optimization potential
